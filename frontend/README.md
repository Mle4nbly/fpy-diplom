# Дипломный проект по профессии "Fullstack-разработчик на Python"

## Описание проекта

Данный проект представляет собой облачное хранилище файлов с базовым функционалом, реализованное в рамках дипломной работы по курсу Fullstack-разработки. 

Пользователь может загружать, хранить, управлять, скачивать и делиться файлами через веб-интерфейс. 

Приложение поддерживает аутентификацию, работу с базой данных и файловой системой сервера.

## Технологический стэк

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

- React

## API документация

Все запросы осуществляются через REST API.

API использует аутентификацию пользователей Django. Аутентификация реализована с использованием Token Authentication Django REST Framework.

Запросы, требующие авторизации, должны содержать токен (DRF Token).

Базовый URL — ```http://localhost:8000/api/```

### Аутентификация
| Метод | Endpoint           | Доступ  | Описание                 |
| ----- | ------------------ | -----------  | ------------------------ |
| POST  | `/users/register/` | Все           | Регистрация пользователя |
| POST  | `/users/login/`    | Все           | Авторизация              |
| POST  | `/users/logout/`   | Авторизация           | Выход из системы         |

### Пользовательские данные
| Метод                | Endpoint           | Доступ  | Описание                 |
| -----                | ------------------ | --------| ------------------------ |
| GET                  | `/users/`          | Админ   | Получение списка пользователей |
| GET                  | `/users/me/`       | Авторизация   | Получение данных текущего пользователя |
| GET / PUT / PATCH / DELETE | `/users/{id}/`     | Админ   | Управление данными пользователя |

### Раота с файлами
| Метод        | Endpoint                | Доступ | Описание                     |
| ------------ | ----------------------- | ----------- | ---------------------------- |
| GET          | `/files/`               | Авторизация | Получение списка файлов      |
| POST         | `/files/`               | Авторизация | Загрузка файла               |
| GET / PUT / PATCH / DELETE | `/files/{id}/` | Авторизация | Управление файлом |
| GET          | `/files/{id}/download/` | Авторизация | Скачивание файла             |

### Публичный доступ к файлам
| Метод        | Endpoint                | Доступ | Описание                     |
| ------------ | ----------------------- | ----------- | ---------------------------- |
| GET          | `/s/{token}/`           | Все | Получение списка файлов      |
| GET         | `/s/{token}/download/`   | Все | Загрузка файла               |

### Административные опрации с файлами
| Метод        | Endpoint                           | Доступ | Описание                        |
| ------------ | ---------------------------------- | ----------- | ------------------------------- |
| GET          | `/files/{username}/`               | Админ   | Список файлов пользователя      |
| POST         | `/files/{username}/`               | Админ   | Загрузка файла пользователю     |
| GET / PUT / PATCH / DELETE | `/files/{username}/{id}/`     | Админ   | Управление файлом пользователя |
| GET          | `/files/{username}/{id}/download/` | Админ   | Скачивание файла                |

## Установка и запуск проекта
### Требования

Для работы с приложением рекомендуется использовать актуальные версии библиотек и фреймворков:
- Python 3.11+
- Django 5+
- Node.js 18+
- npm 9+
- React 18+
- PostgreSQL 14+
- Git

### Клонирование репозитория
В консоли:
```Bash
git clone https://github.com/username/cloud-storage.git
cd cloud-storage
```

### Настройка backend
В консоли:
```Bash
cd backend
python -m venv venv
```
### Активация

Windows:
```Bash
venv\Scripts\activate
```

Linux / macOS:
```Bash
source venv/bin/activate
```
### Установка зависимостей
```Bash
pip install -r requirements.txt
```

### Настройка базы данных
1. Создать базу данных PostgreSQL
2. Создать в директории backend файл `.env`
3. Указать параметры подключения в `.env`

Необходимые переменные:
```js
DB_NAME='Название БД'
DB_USERNAME='Имя пользователя для доступа к БД'
DB_PASSWORD='Пароль пользователя'
DB_HOST='localhost'
DB_PORT='5432'
```

### Переменные окружения

#### Backend
Помимо параметров подключения к БД нам нужно указать перменные `SECRET_KEY` и `DEBUG`. 

Для локальной развертки следует в значение поля `DEBUG` указать `True`. 

`SECRET_KEY` нам нужно сгенерировать локально:
```Bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```
После чего в консоли должна появиться строка типа:
```Bash
django-insecure-...
```
Скопируйте и вставьте ее в поле `SECRET_KEY` в файле `.env`

#### Frontend
Для корректной работы приложения также требуется создать в директории `frontend` файл `.env.local`.

Внутри файла:
```Bash
VITE_API_URL=http://localhost:8000
VITE_CLIENT_URL=http://localhost:5173
```

### Применение миграций
В консоли:
```Bash
python manage.py migrate
```

Для работы с Django Admin нужно создать суперпользователя:
```Bash
python manage.py createsuperuser
```

### Запуск backend
В консоли:
```Bash
python manage.py runserver
```

### Настройка и запуск frontend
В консоли директории проекта:
```Bash
cd frontend
npm install -d
```

После установки для запуска:
```Bash
npm run dev
```
